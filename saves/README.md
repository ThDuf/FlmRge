# Parcours sauvegardés (JSON)

L'éditeur de piste y dépose les parcours sauvegardés (bouton **Sauver**) :

```json
{
  "name": "parcours_20250101_120000",
  "code": "abKcd...u",
  "saved_at": "2025-01-01T12:00:00"
}
```

Le bouton **Charger** recharge le plus récent. Tu peux aussi éditer les
fichiers à la main : `code` = séquence de lettres de tuiles (a-u / A-U).
